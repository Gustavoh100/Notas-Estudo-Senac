# Desenvolvimento Web - Resumo Essencial

## Objetivos

* Entender o que é Desenvolvimento Web.
* Diferenciar Front-end e Back-end.
* Conhecer os fundamentos de HTML, CSS e JavaScript.

---

## O que é Desenvolvimento Web?

Área responsável pela criação de:

* Sites
* Sistemas
* Bancos de dados
* APIs

Exemplos: Google, Facebook, Amazon e Correios.

---

## Front-end x Back-end

### Front-end

Parte visual da aplicação.
É o que o usuário vê e utiliza.

### Back-end

Parte responsável pelas regras de negócio, autenticação, cadastros e processamento de dados.

---

# HTML (HyperText Markup Language)

Linguagem de marcação usada para estruturar páginas web.

### Funções

* Criar a estrutura da página.
* Organizar conteúdos.
* Definir elementos visuais.

### Tags importantes

```html
<head>
<title>
<body>
<header>
<footer>
<section>
<article>
<nav>
<div>
<span>
<img>
<ul>
<ol>
<li>
<p>
```

### Exemplo

```html
<p>Olá Mundo</p>
<br>
```

---

# CSS (Cascading Style Sheets)

Responsável pela aparência da página.

### Funções

* Cores
* Fontes
* Bordas
* Espaçamentos
* Layout
* Responsividade

### Benefícios

* Separação entre conteúdo e visual.
* Reutilização de estilos.
* Facilidade de manutenção.

---

# JavaScript (JS)

Linguagem de programação que adiciona comportamento e interatividade às páginas web.

### Principais usos

#### Interatividade

* Cliques
* Animações
* Atualizações sem recarregar a página

#### Manipulação do DOM

Permite alterar elementos HTML em tempo real.

#### Validação de Formulários

Ajuda o usuário a corrigir erros antes do envio.

#### Comunicação Assíncrona

Busca e envia dados sem travar a interface usando:

* fetch()
* async/await
* APIs externas
