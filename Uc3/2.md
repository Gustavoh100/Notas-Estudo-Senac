# JavaScript e DOM — Resumo Essencial

## JavaScript

JavaScript é a linguagem responsável por adicionar comportamento dinâmico às páginas web.

### Principais Funções

* Interatividade e dinamismo
* Manipulação do DOM
* Validação de formulários
* Comunicação assíncrona

# DOM (Document Object Model)

O DOM é a representação do HTML em forma de árvore.

Cada elemento HTML é um nó que pode ser acessado e modificado pelo JavaScript.

### Exemplo Simplificado

```text
html
 └─ body
     ├─ header
     ├─ main
     └─ footer
```

---

# Métodos Mais Importantes

## getElementById()

Seleciona um elemento pelo ID.

```javascript
const titulo = document.getElementById("titulo");
```

Uso: acessar elementos únicos da página.

---

## querySelector()

Seleciona o primeiro elemento que corresponde a um seletor CSS.

```javascript
const botao = document.querySelector(".btn");
```

Uso: maior flexibilidade na seleção de elementos.

---

## createElement()

Cria um novo elemento HTML.

```javascript
const p = document.createElement("p");
```

Uso: criar elementos dinamicamente.

---

## appendChild()

Adiciona um elemento dentro de outro.

```javascript
document.body.appendChild(p);
```

Uso: inserir elementos no DOM.

---

# Eventos Mais Importantes

## click

Executado quando o usuário clica em um elemento.

```javascript
botao.addEventListener("click", minhaFuncao);
```

---

## submit

Executado ao enviar um formulário.

```javascript
form.addEventListener("submit", enviarFormulario);
```

---

## mouseover

Executado quando o mouse passa sobre um elemento.

```javascript
div.addEventListener("mouseover", mostrarInfo);
```

---

## keydown

Executado quando uma tecla é pressionada.

```javascript
document.addEventListener("keydown", capturarTecla);
```
