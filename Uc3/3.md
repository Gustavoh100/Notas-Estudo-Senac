# Estruturas de Condição (IF / ELSE)

## Objetivo da Aula

* Estruturas de condição (`if` / `else`)
* Operadores relacionais
* Operadores lógicos

---

# O que é uma Estrutura de Condição?

Permite que o programa tome decisões com base em condições definidas.

### Exemplo

```javascript
let idade = 18;

if (idade >= 18) {
    console.log("Maior de idade");
}
```

---

# Operadores Relacionais

Usados para comparar valores.

Retornam:

* `true` (verdadeiro)
* `false` (falso)

| Operador      | Significado    |
| ------------- | -------------- |
| `==` ou `===` | Igual          |
| `!=` ou `!==` | Diferente      |
| `>`           | Maior          |
| `<`           | Menor          |
| `>=`          | Maior ou igual |
| `<=`          | Menor ou igual |

### Exemplos

```javascript
a === b
a !== b
a > b
a < b
a >= b
a <= b
```

---

# Operadores Lógicos

Utilizados para combinar condições.

| Operador | Significado |   |         |
| -------- | ----------- | - | ------- |
| `&&`     | E (AND)     |   |         |
| `        |             | ` | OU (OR) |
| `!`      | NÃO (NOT)   |   |         |

### Exemplos

```javascript
idade >= 18 && possuiCarteira
```

```javascript
idade >= 18 || autorizado
```

```javascript
!logado
```

---

# IF

Executa um bloco de código quando a condição for verdadeira.

```javascript
if (nota >= 7) {
    console.log("Aprovado");
}
```

---

# IF / ELSE

Permite executar um bloco caso a condição seja verdadeira e outro caso seja falsa.

```javascript
if (nota >= 7) {
    console.log("Aprovado");
} else {
    console.log("Reprovado");
}
```

---

# IF / ELSE IF / ELSE

Usado quando existem várias condições.

```javascript
if (nota < 3) {
    console.log("Horrível");
}
else if (nota < 7) {
    console.log("Dá pra melhorar");
}
else {
    console.log("Excelente");
}
```

---

# Exemplo de Prova

Calcular a média de 3 notas:

* Média < 3 → "Horrível"
* Média < 7 → "Dá pra melhorar"
* Média ≥ 7 → "Excelente"

```javascript
let media = (n1 + n2 + n3) / 3;

if (media < 3) {
    console.log("Horrível");
}
else if (media < 7) {
    console.log("Dá pra melhorar");
}
else {
    console.log("Excelente");
}
```

# O que Decorar para a Prova

```text
IF           -> executa se a condição for verdadeira
ELSE         -> executa caso contrário
ELSE IF      -> adiciona novas condições

==  ===      -> igual
!=  !==      -> diferente
>            -> maior
<            -> menor
>=           -> maior ou igual
<=           -> menor ou igual

&&           -> E
||           -> OU
!            -> NÃO
```

## Resumo Final

```text
1. Comparar valores -> operadores relacionais
2. Combinar condições -> operadores lógicos
3. Tomar decisões -> if / else
4. Múltiplas decisões -> else if
```
