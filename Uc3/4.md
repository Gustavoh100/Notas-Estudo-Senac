# React — Resumo Essencial

## O que é React?

React é uma biblioteca JavaScript utilizada para criar interfaces de usuário (UI). Foi desenvolvida pelo Facebook e utiliza uma abordagem baseada em componentes reutilizáveis.

---

# Por que usar React?

### Vantagens

* Reutilização de código através de componentes.
* Melhor desempenho com Virtual DOM.
* Grande comunidade e ecossistema.

---

# Componentes

A interface é dividida em pequenas partes reutilizáveis chamadas componentes.

Cada componente possui uma responsabilidade específica dentro da aplicação.

### Exemplo

```jsx
function Header() {
  return <h1>Meu Site</h1>;
}
```

---

# Node.js e NPM

Para desenvolver aplicações React é necessário ter o Node.js instalado para utilizar os comandos NPM.

---

# Criando Projetos React

## Antigo (Create React App)

```bash
npx create-react-app my-app
```

O Create React App (CRA) foi muito utilizado, mas foi descontinuado.

---

## Atual (Vite)

```bash
npm create vite@latest .
```

O curso utiliza o Vite para criar projetos React.

---

# Estrutura Básica do Projeto

```text
public/
src/
 ├─ assets/
 ├─ App.css
 ├─ App.jsx
 ├─ index.css
 └─ main.jsx
```

### Função de cada pasta/arquivo

| Item      | Função                         |
| --------- | ------------------------------ |
| public    | Arquivos públicos              |
| assets    | Imagens e arquivos processados |
| App.jsx   | Componente principal           |
| App.css   | Estilo do App                  |
| index.css | Estilo global                  |
| main.jsx  | Renderiza a aplicação          |

---

# public x assets

## public

* Não passa por otimização.
* Pode ser acessado diretamente por URL.
* Ideal para arquivos estáticos.

## assets

* Passa por otimização do build.
* Deve ser importado no código.
* Ideal para imagens e recursos da aplicação.

---

# JSX

JSX (JavaScript XML) permite escrever HTML dentro do JavaScript.

### Exemplo

```jsx
function App() {
  return (
    <h1>Olá React</h1>
  );
}
```

---

# Props

Props são propriedades enviadas para componentes.

### Exemplo

```jsx
function Usuario(props) {
  return <h2>{props.nome}</h2>;
}

<Usuario nome="Gustavo" />
```

---

# Fluxo Básico de um Projeto React

```text
1. Instalar Node.js
2. Criar projeto com Vite
3. Criar componentes
4. Utilizar JSX
5. Passar dados com Props
6. Renderizar no App.jsx
```
