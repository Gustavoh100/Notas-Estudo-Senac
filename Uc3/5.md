# React Router DOM — Resumo Essencial

## O que são Pages?

Além dos componentes, aplicações React também possuem páginas (Pages).

Para navegar entre páginas é necessário utilizar um sistema de rotas.

---

# React Router DOM

Biblioteca responsável pela navegação em aplicações React.

### Funções

* Criar rotas.
* Navegar entre páginas.
* Evitar recarregamento da página.
* Criar aplicações SPA (Single Page Application).

---

# O que é SPA?

SPA (Single Page Application) é uma aplicação que troca o conteúdo da tela sem recarregar a página inteira.

### Fluxo

```text
Usuário clica
      ↓
React Router
      ↓
Nova página é exibida
      ↓
Sem reload
```

# Arquivos Importantes

## main.jsx

Responsável por iniciar a aplicação e envolver o projeto com o Router.

```jsx
import { BrowserRouter } from "react-router-dom";

<BrowserRouter>
  <App />
</BrowserRouter>
```

---

## App.jsx

Define as rotas da aplicação.

```jsx
import { Routes, Route } from "react-router-dom";

<Routes>
  <Route path="/" element={<Home />} />
  <Route path="/about" element={<About />} />
</Routes>
```

---

# Navegação

Para trocar de página usa-se o componente `Link`.

```jsx
import { Link } from "react-router-dom";

<Link to="/">Home</Link>
<Link to="/about">Sobre</Link>
```
